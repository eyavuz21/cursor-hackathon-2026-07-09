# Cursor Hackathon — 2026 July 09

Project scaffold for the 2026 July 09 Cursor Hackathon.

Built with **Next.js 16** (App Router), **TypeScript**, and **Tailwind CSS**. Deployed on **Vercel** with preview deployments enabled — every branch and PR gets its own shareable URL.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and edit `src/app/page.tsx`.

## Deployments

- **Production** deploys from the `main` branch.
- **Preview** deployments are created automatically for every branch and pull request. Preview URLs are publicly accessible (deployment protection is disabled) so teammates and AI agents can open them without signing in.
